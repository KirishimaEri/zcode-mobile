# Zcode Mobile（安卓版）

非官方的 ZCode（z.ai AI 编程工作区）安卓移动连接客户端。扫桌面端「移动端远程控制」二维码，即可在手机上查看和操控 ZCode 会话。

## 原理

ZCode 桌面端远程控制二维码的内容是一个云端托管页面 URL：

```
https://zcode.z.ai/remote/v4?sid=<deviceSid>&hash=<口令哈希>&t=<时间戳>&mid=<机器ID>&name=<主机名>&app_version=<版本>
```

桌面端主动连接 `wss://zcode.z.ai/ws` 云端中继，手机页面与桌面端之间的配对、加密转发全部由官方云端页面完成。本 App 负责：扫码 / 相册导入 / 粘贴 → 校验 URL → 全屏 WebView 打开官方连接页，并维护连接历史与自动重连。App 自身没有后端，也不实现任何私有协议，配对 URL 只存在应用私有目录。

## 功能

- **扫码连接**：相机实时识别（ML Kit）
- **相册导入**：截图桌面端二维码后从相册导入（模拟器/无第二台手机时也适用）
- **粘贴连接**：直接粘贴远程控制弹窗里显示的链接（宽松校验）
- **连接历史**：按最近使用排序，一键重连，可删除
- **自动重连**：启动 App 自动恢复上次连接（可关）
- **屏幕常亮**：连接期间保持常亮（可关）

## 构建

```bash
# 需要 JDK 17+ 与 Android SDK（compileSdk 35）
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

## 安装到手机

1. 把 `app-debug.apk` 传到手机（微信文件传输助手 / USB / 网盘均可）
2. 手机上点开 APK，允许"安装未知来源应用"
3. 打开 App → 首页点「扫码连接」，扫桌面端左下角手机图标的远程控制二维码

## 注意事项

- 配对链接等同桌面端钥匙，请勿分享；怀疑泄露就在桌面端刷新二维码
- 官方同一时刻只允许一个手机页面连接，新连接会踢掉旧的
- 需要桌面端远程控制处于开启状态；关掉弹窗不会停远控，要点「停止」
- 本项目与 z.ai 无关，仅供个人使用
